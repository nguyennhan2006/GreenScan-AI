# Roadmap

## V1.0 Baseline

- deterministic end-to-end pipeline;
- PDF/OCR/table intake;
- hybrid retrieval;
- five-state verification;
- evidence pack, audit and tests.

## V1.1 Data quality

- annotated Vietnamese pilot set;
- numeric/table extraction benchmark;
- document-source registry and duplicate detection;
- reviewer UI and override workflow.

## V1.2 Retrieval quality

- multilingual embedding adapter;
- cross-encoder reranker;
- query rewriting only when benchmarked;
- top-k dynamic selection and distractor filtering.

## V1.3 Verification quality

- claim-specific calculators;
- time-series and intensity-vs-absolute analysis;
- legal taxonomy engine;
- independent-source connectors.

## V2

- workflow engine and persistent database;
- hierarchical/graph retrieval for thematic cases;
- controlled multi-agent decomposition when it outperforms the orchestrator baseline;
- monitoring dashboard, drift alerts and model/rubric registry.
