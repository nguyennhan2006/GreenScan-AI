# Prioritised implementation backlog

## P0 — Pilot readiness

- Create 50–100 adjudicated Vietnamese claims across at least five industries.
- Add actual PDF table and scanned-page fixtures with permission to use.
- Define evidence admissibility and reviewer adjudication handbook.
- Add persistent run metadata store and reviewer override endpoint.
- Add input limits, authentication and private object storage.

## P1 — Accuracy

- Benchmark Nanonets-OCR-s and two alternative OCR/layout parsers.
- Add multilingual embedding and cross-encoder reranker adapters.
- Add metric-specific calculators for emissions, renewable energy, waste, water and green-finance proceeds.
- Add period, scope, unit and absolute-vs-intensity normalisation.
- Add source-quality and independent-assurance models.

## P2 — Scale and thematic analysis

- Query router for local, multi-hop and thematic tasks.
- Hierarchical summaries for long reports.
- Graph retrieval for cross-document themes only after benchmark approval.
- Batch analysis, caching and asynchronous jobs.

## P3 — Operations

- Monitoring dashboard, drift detection and dataset slice reporting.
- Model/prompt/rubric registry.
- Cost budgets and provider failover.
- Staged releases, canary evaluation and rollback automation.
