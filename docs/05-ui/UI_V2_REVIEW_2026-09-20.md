## Điểm cố ý khác mockup, để hội đồng không đọc nhầm

- Không có số điểm/KPI to ở bất kỳ màn nào; điểm rủi ro chỉ ở khối "Phân rã rủi ro" chữ nhỏ, 9 thanh.
- `INSUFFICIENT_EVIDENCE` màu sky (không đỏ, không xám "lỗi"), kèm câu cố định "kết quả hợp lệ".
- `UNSUPPORTED` màu tím để không lẫn với `INSUFFICIENT_EVIDENCE` (trước đây cam).
- Không có chữ *vi phạm / gian lận / sai phạm* trong chuỗi UI ngoài câu disclaimer "không đồng nghĩa vi phạm" (đã quét bằng SSR render 11 màn với dữ liệu thật).
- Sidebar: mục cần phiên (Tổng quan, Tuyên bố, Xét duyệt, Xuất) hiển thị mờ khi chưa mở phiên thay vì ẩn — bản đồ sản phẩm luôn nhìn thấy.

## Chạy thử

```bash
# API
.venv/Scripts/python.exe -m quantum_gw.cli serve --port 8000
# UI
cd frontend && npm install && npm run dev      # http://localhost:5173
```

Luồng demo 7 phút (EXECUTION_PLAN §4): `#/runs` → mở run đã lưu → `#/runs/<id>/claims` → một claim → cuộn Thuộc tính → Bằng chứng → Mở trang → Kiểm tra số → Pháp lý → Rủi ro → Xác nhận/Ghi đè → `#/runs/<id>/export`.
