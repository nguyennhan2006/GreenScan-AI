# Project status

This repository is a functional V1 engineering baseline. It is suitable for local demonstrations, CI, schema discussion and iterative experiments. It is not yet a validated production decision system.

## Before a real pilot

- appoint domain and legal-rule owners;
- build an adjudicated Vietnamese dataset;
- establish document confidentiality controls;
- calibrate thresholds by industry and claim type;
- validate OCR/table extraction on actual reports;
- add external/legal data connectors;
- define reviewer SLAs and override governance.
