# GreenScan-AI
Dự án phát triển một hệ thống AI hỗ trợ phát hiện rủi ro greenwashing trong lĩnh vực tài chính Việt Nam. Hệ thống tập trung phân tích các tài liệu công bố của doanh nghiệp như báo cáo thường niên, báo cáo ESG/phát triển bền vững, báo cáo tài chính, thông tin trái phiếu xanh, khoản vay xanh, dữ liệu môi trường, dữ liệu pháp lý và nguồn tin bên ngoài
